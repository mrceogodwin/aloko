# Aloko home-screen assets

The home screen expects the approved PNG artwork in this directory:

- hero-art.png
- cat-auto.png
- cat-electronics.png
- cat-fashion.png
- cat-furniture.png
- cat-home-living.png
- cat-kids.png
- cat-more.png
- cat-sports.png
- promo-bulk.png
- promo-decluttering.png
- promo-giveaway.png
- listing-fridge.png
- listing-iphone.png
- listing-macbook.png
- listing-sofa.png
- logo-mark.png

Copy the contents of the supplied `aloko-public-assets.zip` into this directory (preserving the filenames). The UI references these as `/assets/aloko/<filename>`.

The binary images are intentionally not replaced with generated drawings or stock imagery.
